- [ ] 全部媒体 ID 有单位、模式、查价名称、数量/usage 来源、目标渠道、源零售价、供应商成本证据状态、目标价提案、适用倍率和账单样例。

- [ ] 价格页/模型配置/渠道表单/日志用量单位一致；按秒/分钟/字符/张/次/token/档位展示清楚，新文本七语言覆盖。
- [ ] 预扣/结算/退款与钱包和订阅账务精确一致；变更分组、渠道和模型价不改既有任务快照；重复状态不重记。
- [ ] 禁用排除、受限测试组启用、正式组可见范围、别名/分流、原模型回归有证据。
- [ ] 真实端到端证据覆盖每个模型或已证明等价的别名，验证媒体取回与账单；外部阻塞逐项标出，不假称完整。
